48498: Test Thing Upstairs Overlap
Used by the routine at ScriptRoutine_ThingUpstairsChase.
Return 1 in A when the Thing Upstairs entity overlaps Berk on X (BerkXCoordinateCopy / BerkXExtentCopy) and the camera-follow entity (StateData_Berk) on Y while Berk's room copy is 0. Otherwise return 0.
Input
IX Address of the Thing Upstairs entity's complex state data
