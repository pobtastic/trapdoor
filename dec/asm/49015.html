49015: Script Routine: (40) Task-two entity action
Mark the bird script as active so later task-two steps can run.
ScriptRoutine_TaskTwoArmScriptFlags 49015 PUSH HL Stash HL on the stack.
49016 LD HL,29363 Point HL at the game event flags (GameEventFlags).
49019 SET 7,(HL) Set "task entity script is active" (bit 7 of GameEventFlags).
49021 SET 4,(HL) Set "task-two / upstairs event latch" (bit 4 of GameEventFlags).
49023 LD A,(29376) Load A with the entity spawn timer (EntitySpawnTimer).
49026 CP 4 Is entity spawn timer equal to 4? If not, jump to ScriptRoutine_TaskTwoArmScriptFlags_NextInstruction.
49028 JR NZ,ScriptRoutine_TaskTwoArmScriptFlags_NextInstruction
49030 LD HL,29365 Point HL at the task-two flags (TaskTwoFlags).
49033 SET 2,(HL) Set "spawn / random-walk latch" (bit 2 of TaskTwoFlags).
Flags armed: restore HL and continue at the next script instruction.
ScriptRoutine_TaskTwoArmScriptFlags_NextInstruction 49035 POP HL Restore HL from the stack.
