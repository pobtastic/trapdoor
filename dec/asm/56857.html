56857: Print Status Messages
Used by the routines at GameStart and Update_Berk_State.
Print the Learner/Super rating line from Messaging_TooLateIveChangedMyMind, then a task-progress line chosen from the task status flags (TaskStatusFlags).
Choose the rating message from the Learner Berk mode flag (Flag_LearnerBerkMode).
Print_StatusMessages 56857 LD A,(29353) Load A with the Learner Berk mode flag (Flag_LearnerBerkMode).
56860 OR A Is Learner mode selected? If so, use the Learner rating at Messaging_AsALearnerIThinkYouAre.
56861 JR NZ,Print_StatusMessages_Learner
56863 LD HL,56823 Point HL at the Super Berk rating message (Messaging_AsASuperberkIRateYouAs).
56866 JR Print_StatusMessages_PrintRating Skip to print it at Print_StatusMessages_PrintRating.
Use the Learner Berk rating message at Messaging_AsALearnerIThinkYouAre.
Print_StatusMessages_Learner 56868 LD HL,56789 Point HL at the Learner rating message (Messaging_AsALearnerIThinkYouAre).
Print the chosen Learner / Super rating line via Print_EncodedMessage.
Print_StatusMessages_PrintRating 56871 CALL Print_EncodedMessage Call Print_EncodedMessage to print the encoded rating message.
Choose a task-progress message index from TaskStatusFlags / DialogueLineIndex.
56874 LD HL,57101 Point HL at the task briefing/progress table (Messaging_ACompleteFailureYoureFired).
56877 LD A,(29364) Load the task status flags (TaskStatusFlags).
56880 OR A Any task-status bits set? If not, use the dialogue line index at Print_StatusMessages_UseDialogueIndex.
56881 JR NZ,Print_StatusMessages_FromTaskFlags
Fall back to dialogue-line index DialogueLineIndex when no task-status bits are set.
Print_StatusMessages_UseDialogueIndex 56883 LD A,(29360) Load the dialogue line index (DialogueLineIndex).
56886 INC A Advance it by one for the table walk.
56887 JR Print_StatusMessages_PrintIndexed Jump to Print_StatusMessages_PrintIndexed to print that indexed string.
Derive the progress message from task-status flags (TaskStatusFlags), including Drutt's type-24 catch.
Print_StatusMessages_FromTaskFlags 56889 LD A,(29364) Reload the task status flags (TaskStatusFlags).
56892 BIT 4,A Did Drutt collect a type-24 object (bit 4)? If so, use index 6.
56894 JR Z,Print_StatusMessages_SafeLootBit
56896 LD A,6 Load message index 6.
56898 JR Print_StatusMessages_PrintIndexed Jump to Print_StatusMessages_PrintIndexed to print the indexed status string.
If Drutt caught a type-28 object (bit 5), use progress message index 7.
Print_StatusMessages_SafeLootBit 56900 BIT 5,A Did Drutt collect a type-28 object (bit 5)? If not, fall back to Print_StatusMessages_UseDialogueIndex.
56902 JR Z,Print_StatusMessages_UseDialogueIndex
56904 LD A,7 Load message index 7.
Print the indexed progress string via Print_MessageString, then seed menu music and wait for a key via Seed_MenuMusicAndWaitForKey.
Print_StatusMessages_PrintIndexed 56906 CALL Print_MessageString Call Print_MessageString to print the indexed string at HL.
56909 CALL Seed_MenuMusicAndWaitForKey Call Seed_MenuMusicAndWaitForKey to seed the menu music and wait for a key.
56912 RET Return.
