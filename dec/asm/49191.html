49191: Script Routine: (39) Task-two entity action
Spawn or refresh a helper entity from the current task-two state.
Input
IX Address of complex state data for an entity

49194 LD B,(IX+6) Load B with the current entity's y-extent.
49197 LD C,(IX+7) Load C with the current entity's x-coordinate.
49200 LD IY,36823 Point IY at the spawned-helper entity (StateData_Complex_17).
49204 LD (IY+0),6 Write 6 to the referenced entity's entity type.
49208 LD (IY+4),A Set the referenced entity's room index.
49211 INC C Advance the helper's x-coordinate in C by one.
49212 LD (IY+7),C Store C in the referenced entity's x-coordinate.
49215 INC C Advance the helper's x-extent base in C by one.

49219 INC B Step the Y value in B on by one.
49220 LD (IY+5),B Store B in the referenced entity's y-coordinate.
49223 INC B Step the Y value in B on by one.

49231 LD A,(29363) Load A with the game event flags (GameEventFlags).

49239 LD A,(29376) Load A with the entity spawn timer (EntitySpawnTimer).
