44449: Update Timed Events
Used by the routine at GameStart.
Once per frame: run timed room events, fanfares and the script-temporary countdown while a task is active.
Update_Timed_Events 44449 LD A,(29390) Load A with the timed event latch (TimedEventLatch).
44452 OR A Is timed event latch zero? If so, return.
44453 RET Z
44454 LD IX,36221 Point IX at the dumb-waiter entity (36221).
44458 CP 28 Is timed event latch equal to 28? If not, jump to Update_Timed_Events_AdvanceTypeAndSound.
44460 JR NZ,Update_Timed_Events_AdvanceTypeAndSound
44462 XOR A Clear the timed event latch.

44466 LD IX,(36233) Load IX from the trap door entity pointer (36233).
44470 LD A,(IX+0) Fetch the current entity's type for the type test.

44475 JR C,Update_Timed_Events_TrapDoorLayout
44477 BIT 6,(IX+1) Is bit 6 of the current entity's flags byte 1 set? If not, jump to Update_Timed_Events_TrapDoorLayout.
44481 JR Z,Update_Timed_Events_TrapDoorLayout
44483 RES 6,(IX+1) Reset bit 6 of the current entity's flags byte 1.
44487 INC (IX+4) Advance this entity into the next room.
44490 INC (IX+5) Move this entity one character down.

44496 INC (IX+4) Advance this entity into the next room.
44499 INC (IX+5) Move this entity one character down.
44502 INC (IX+6)
44505 LD HL,29363 Point HL at the game event flags (GameEventFlags).
44508 RES 3,(HL) Clear "object has been offered to the trap" (bit 3 of GameEventFlags).
