29366: Task Three Flags
Flags for the task-three (boiled slimies / feeding) state machine. Bit names below are taken from the Bad Tempered Thing dialogue gates and the stove / put-down writers that set or clear them.
Bit Name Set / clear
0 MobileHeater no SET/RES site found
1 Slimies set by 61712; tested by 55553
2 SlimyLoose set by 46081 / 50940; cleared by Update_Stove
4 BoilEmUp set by ScriptRoutine_TaskThreeBerkRightWindow_SetFlagsAndLayout; cleared by Update_Stove; tested by 55591
5 BoilEmUpLatch set by ScriptRoutine_TaskThreeBerkRightWindow_SetFlagsAndLayout; cleared by Update_Stove / 50071
6 StoveReady set by Update_Stove when StoveTick reaches 4
7 StoveUpdated set by Update_Stove; tested by ScriptRoutine_TaskThreeBerkRightWindow_SetFlagsAndLayout
Bit 0 (MobileHeater) gates Messaging_MobileHeater ("Mobile Heater") / Messaging_TheStovesNoHelp ("The Stove's No Help", 55585); no SET/RES site found.
Bit 1 (Slimies) gates Messaging_Slimies ("Slimies"); set by 61712 on put-down of type 9; tested by 55553.
Bit 2 (SlimyLoose) gates Messaging_SlimyLoose ("Slimy Loose !"); set by 46081 / 50940; cleared by Update_Stove; if set, 55559 skips the line.
Bit 4 (BoilEmUp) gates Messaging_BoilEmUp ("Boil'Em Up !") / Messaging_Flame ("Flame ?"); set by ScriptRoutine_TaskThreeBerkRightWindow_SetFlagsAndLayout with 5; cleared by Update_Stove; tested by 55591.
Bit 5 (BoilEmUpLatch) is the companion set with BoilEmUp by ScriptRoutine_TaskThreeBerkRightWindow_SetFlagsAndLayout; cleared by Update_Stove / 50071; no BIT reader found.
Bit 6 (StoveReady) gates Messaging_TooSoon ("Too Soon ?") / Messaging_HotStuff ("Hot Stuff", 55573) and Messaging_GotAllSlimies ("Got All Slimies ?", 55579); set by Update_Stove when StoveTick reaches 4.
Bit 7 (StoveUpdated) is set by Update_Stove; tested by ScriptRoutine_TaskThreeBerkRightWindow_SetFlagsAndLayout before it sets BoilEmUp / BoilEmUpLatch and swaps the cauldron layout.
