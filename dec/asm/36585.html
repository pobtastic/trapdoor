36585: State Data: Complex Entities
Table of complex entity state records (0014 bytes each). Backed up to Buffer_EntityStateBackup by Backup_Entity_And_Game_State. Field layout: 0 type; 1–3 flags; 4 room 5/6 y and y-extent; 7/8 x and x-extent 9 direction/state; 10/11 graphic layout pointer 12/13 extra state. Flags byte 3 at offset 3 (IX+3) for Berk and most movers:
Bit Meaning
0 Script-locked (ignore input; also set while facing / moving up)
1 Facing left (reset = facing right)
2 Mid-interaction / push latch
3 Bit 3 of flags byte 3
4 Bit 4 of flags byte 3 (see Script_PutDown_SetCarryingFlag / ScriptRoutine_PickUpHeld)
5 Bit 5 of flags byte 3
6 Can-fall / gravity latch
7 Rising / special vertical-state latch
Direction / state at offset 9: 1 face left, 2 face right, 4 face down, 8 face up (see script routines ScriptRoutine_FaceRight–ScriptRoutine_FaceDown).
