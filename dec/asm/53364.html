53364: Script Routine: (62) Vat action
Scan nearby entity slots for something the vat can interact with.
Input
IX Address of complex state data for an entity
ScriptRoutine_VatScanNearbySlots 53364 LD E,255 Load E with 255.
53366 LD IY,36767 Point IY at an inactive complex-entity slot (StateData_Complex_13).
53370 LD B,3 Load B with 3 as a loop counter.
Scan nearby type-11 slots for the closest X neighbour within 40 of the vat.
ScriptRoutine_VatScanNearbySlots_ScanEntitySlot 53372 PUSH BC Stash BC on the stack.
53373 LD A,(IY+0) Load A with the referenced entity's entity type.
53376 CP 11 Is referenced entity's entity type equal to 11? If not, jump to ScriptRoutine_VatScanNearbySlots_AdvanceEntitySlot.
53378 JR NZ,ScriptRoutine_VatScanNearbySlots_AdvanceEntitySlot
53380 BIT 7,(IY+1) Is bit 7 of the referenced entity's flags byte 1 set? If so, jump to ScriptRoutine_VatScanNearbySlots_AdvanceEntitySlot.
53384 JR NZ,ScriptRoutine_VatScanNearbySlots_AdvanceEntitySlot
53386 LD A,(IY+5) Load A with the referenced entity's y-coordinate.
53389 CP 29 Is referenced entity's y-coordinate less than 29? If so, jump to ScriptRoutine_VatScanNearbySlots_AdvanceEntitySlot.
53391 JR C,ScriptRoutine_VatScanNearbySlots_AdvanceEntitySlot
53393 LD A,(IX+7) Load A with the current entity's x-coordinate.
53396 SUB (IY+7) Subtract the referenced entity's x-coordinate from A.
53399 LD D,A Copy the signed x-delta into D (bit 7 = sign).
53400 JR NC,ScriptRoutine_VatScanNearbySlots_TrackBestAbsDeltaX Jump to ScriptRoutine_VatScanNearbySlots_TrackBestAbsDeltaX if the subtraction did not underflow.
53402 NEG Negate A to get abs(x-delta).
Keep the nearest in-range candidate in E / TemporaryEntityPointer_Misc.
ScriptRoutine_VatScanNearbySlots_TrackBestAbsDeltaX 53404 CP 40 Is abs(x-delta) less than 40? If not, jump to ScriptRoutine_VatScanNearbySlots_AdvanceEntitySlot.
53406 JR NC,ScriptRoutine_VatScanNearbySlots_AdvanceEntitySlot
53408 CP E Is abs(x-delta) greater than or equal to the best-so-far in E? If so, jump to ScriptRoutine_VatScanNearbySlots_AdvanceEntitySlot.
53409 JR NC,ScriptRoutine_VatScanNearbySlots_AdvanceEntitySlot
53411 LD E,A Store this abs(x-delta) as the new best in E.
53412 LD (53045),IY Store IY in the miscellaneous-entity temp pointer (TemporaryEntityPointer_Misc).
Advance to the next candidate slot and finish the scan when B hits zero.
ScriptRoutine_VatScanNearbySlots_AdvanceEntitySlot 53416 LD BC,14 Each entity record is 0014 bytes long, then load that length into BC.
53419 ADD IY,BC Add the offset in BC to the entity pointer in IY.
53421 POP BC Restore BC from the stack.
53422 DJNZ ScriptRoutine_VatScanNearbySlots_ScanEntitySlot Decrease the loop counter in B and jump to ScriptRoutine_VatScanNearbySlots_ScanEntitySlot if more iterations remain.
53424 LD A,40 Load A with 40 (no-candidate sentinel matching the initial E).
53426 CP E Was no nearer entity found (E still 40)? If carry set, jump to ScriptRoutine_VatScanNearbySlots_NoCandidateNearby.
53427 JP C,ScriptRoutine_VatScanNearbySlots_NoCandidateNearby
53430 LD IY,(53045) Load IY from TemporaryEntityPointer_Misc.
53434 LD A,(IX+4) Load A with the current entity's room index.
53437 CP (IY+4) Does the candidate share this entity's room (IY+4)? If so, jump to ScriptRoutine_VatScanNearbySlots_SameRoomCheckY.
53440 JR Z,ScriptRoutine_VatScanNearbySlots_SameRoomCheckY
53442 JR C,ScriptRoutine_VatScanNearbySlots_SetDirBit2 Jump to ScriptRoutine_VatScanNearbySlots_SetDirBit2 if the result underflowed.
53444 SET 3,(IX+9) Set bit 3 of the current entity's direction / state.
53448 JR ScriptRoutine_VatScanNearbySlots_DeltaSignPlus Jump to ScriptRoutine_VatScanNearbySlots_DeltaSignPlus to continue this routine.
