61224: Script: Set Entity Latch
Set bit 5 of flags byte 2 (IX+2). If bit 4 of flags byte 3 (IX+3) is clear, continue at Script_Shared_SetEventBit to set bit 0 of GameEventFlags.
Input
IX Address of complex state data for an entity
ScriptRoutine_SetLatchRaiseEvent 61224 SET 5,(IX+2) Set bit 5 of the current entity's flags byte 2.
61228 BIT 4,(IX+3) Is bit 4 of flags byte 3 (IX+3) set? If not, jump to Script_Shared_SetEventBit.
