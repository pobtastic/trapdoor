58230: Draw Message Character
Used by the routine at Centre_AndDrawMessageRow.
Draw one double-height message character from the buffer at IX into the attribute/screen pair at HL, then advance. Maps punctuation to fixed glyph indices and ASCII from 0 onward to even glyph slots (two 0008-byte halves per character in Font_MessageCharacters).
Input
HL Attribute-file address for this character
IX Pointer into the decoded message buffer
Stop on row/message terminators; otherwise map the character to a glyph index.
