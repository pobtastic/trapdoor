59793: Blit Display Buffer To Screen
Used by the routine at GameStart.
Compare the primary and secondary display buffers and blit changed tiles to the Spectrum screen. Tiles with attribute bit 7 set are horizontally mirrored via BitmapMirrorLookup (see Blit_DisplayBufferRowLoop).
Choose which display buffer is "live" versus "previous" from DisplayBufferSelectFlag.
Blit_DisplayBuffer 59793 LD IX,22528 Point IX at the attribute file (22528 (attribute buffer)).
59797 LD HL,25504 Point HL at Primary Display Buffer (PrimaryDisplayBuffer).
59800 LD DE,27424 Point DE at Secondary Display Buffer (SecondaryDisplayBuffer).
59803 LD A,(29418) Load A with the display-buffer select flag (DisplayBufferSelectFlag).
59806 OR A Is the display-buffer select flag (DisplayBufferSelectFlag) zero? If so, jump to Blit_DisplayBuffer_AfterSelect.
59807 JR Z,Blit_DisplayBuffer_AfterSelect
59809 EX DE,HL Exchange DE and HL.
After selecting primary/secondary, walk 20 rows × 32 columns for dirty tiles.
