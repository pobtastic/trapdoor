29451: Table: Addresses of Graphic Sets
Base addresses for graphic sets 0–6. Blit_DisplayBufferRow indexes this table with (set × 2) when blitting a display-buffer tile. Layout opcode 244 writes the set index to CurrentGraphicSetIndex. Index 0 is a never-selected placeholder so the live sets stay on 1–6 matching the 244 operands. 244 never selects set 0.
Set Base Tiles Notes
0 0000 — Placeholder
1 Graphics_Set01 179 Room scenery / props
2 Graphics_Set02 143 Shared scenery tiles
3 Graphics_Set03 168 Berk, Drutt, doors, most entities
4 Graphics_Set04 95 Additional scenery
5 Graphics_Set05 101 Trap door / scenery variants
6 Graphics_Set06 60 Extra tiles
Table_GraphicSetAddresses 29451 DEFW 0 Graphics set 0: placeholder (never selected by 244; base 0000).
29453 DEFW Graphics_Set01 Graphics set 1: room scenery / props; see Graphics_Set01.
29455 DEFW Graphics_Set02 Graphics set 2: shared scenery tiles; see Graphics_Set02.
29457 DEFW Graphics_Set03 Graphics set 3: Berk, Drutt, doors, most entities; see Graphics_Set03.
29459 DEFW Graphics_Set04 Graphics set 4: additional scenery; see Graphics_Set04.
29461 DEFW Graphics_Set05 Graphics set 5: trap door / scenery variants, see Graphics_Set05.
29463 DEFW Graphics_Set06 Graphics set 6: extra tiles; see Graphics_Set06.
