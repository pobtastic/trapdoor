60976: Check Entities Near Trap Door
Used by the routine at Open_TrapDoor.
Scan complex entity state starting at StateData_Boney. Returns with the carry flag set when the trap door should open (an entity of type 50 is present and nearby entities have been adjusted). Called by Open_TrapDoor.
Output
F Success marker set if the trap door should open
