48845: Update Task Two Entities
Used by the routine at GameStart.
Once per frame for the "Thing Upstairs" task: refresh helpers, and when the task phase is 2 advance the task-two script at Pointer_TaskTwoScriptPosition.
Update_Task_Two_Entities 48845 CALL Update_Task_Helper_Entities Call Update_Task_Helper_Entities to update the task helper entities.
48848 LD A,(29359) Fetch the current task phase (CurrentTaskPhase).
48851 CP 2 Is the phase "run task-two scripts" (2)? If not, return.
48853 RET NZ
48854 LD HL,(29397) Load the task-two script position (Pointer_TaskTwoScriptPosition).
48857 LD (29391),HL Copy it into the active script cursor (Pointer_ActiveScriptCursor).
48860 CALL Update_TaskTwoEntityState Call Update_TaskTwoEntityState to advance that script / entity state.
48863 LD HL,(29391) Reload the (possibly updated) temporary script pointer.
48866 LD (29397),HL Write it back to the task-two script position (Pointer_TaskTwoScriptPosition).
48869 RET Return.
