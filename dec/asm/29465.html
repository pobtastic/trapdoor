29465: Bitmap Mirror Image Lookup Table
Entry n holds n with its eight bits in reverse order, so bit 7 swaps with bit 0, bit 6 with bit 1, and so on. Blit_DisplayBufferRowLoop passes each of a tile's eight bitmap bytes through it when the tile's attribute bit 7 is set, which draws the tile mirrored left to right, so one copy of the graphics serves both facing directions.
