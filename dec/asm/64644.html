64644: Menu Music Workspace
Working bytes for the two-channel menu tune. MenuMusic_Workspace and 64645 hold the latest stream bytes; 64646 holds the border and speaker output value written to port 254; 64647/64649 are stream one's cursor and reload address; 64651/64653 are stream two's; 64655 holds the shared delay phase.
MenuMusic_Workspace 64644 DEFB 244 Latest byte from music stream one.
64645 DEFB 19 Latest byte from music stream two.
64646 DEFB 0 Border and speaker bits for port 254.
64647 DEFW 65132 Stream one cursor.
64649 DEFW 65100 Stream one reload address.
64651 DEFW 65354 Stream two cursor.
64653 DEFW 65322 Stream two reload address.
64655 DEFB 232 Shared delay phase for both channels.
