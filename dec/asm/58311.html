58311: Plot Message Glyph Half
Used by the routine at Draw_MessageCharacter.
Write one 0008-byte half-glyph from the message font into the screen bitmap under attribute address HL. Applies the roll/shift mode in 56735 and the inverse shift count in 56736.
Input
HL Attribute-file address for this character
DE Glyph half-index (×0008 into Pointer_CurrentCharacterSet)
