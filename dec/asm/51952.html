51952: Script Routine: (80) Task-four entity action
Clear the task-four script flags so the next task-four beat can start cleanly.
ScriptRoutine_TaskFourClearScriptFlags 51952 LD HL,29363 Point HL at the game event flags (GameEventFlags).
51955 RES 7,(HL) Clear bit 7 of GameEventFlags (task entity script active).
51957 RES 4,(HL) Clear bit 4 of GameEventFlags (upstairs event latch).
51959 LD A,40 Load A with 40.
51961 LD (29426),A Set the game tick counter (GameTickCounter).
51964 JR Update_TaskFour_StartEntity Jump to Update_TaskFour_StartEntity to start the entity.
