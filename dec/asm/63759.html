63759: Table: Sound Parameters
Eight-byte parameter blocks for sounds 1–20. Play_QueuedSound forms IX=63751+(index×8). The base 63751 is the operand byte of JR NZ in Queue_Sound; it is never read as a parameter because indexes start at 1, so sound 1 begins here. Layout:
Offset Meaning
0 Outer repeat count (C)
1 Pulse count (B)
2 Speaker-off delay (E)
3 Speaker-on delay (D)
4 Per-pulse delta added to the on-delay
5 Per-pulse delta added to the off-delay
6 Flags / waveform high byte (bit 7 set = square wave only)
7 Waveform low byte when bit 7 of 6 is clear
