F5CA: Print Control Key Labels
Used by the routine at MainMenu_SelectOptions.
Print the control-key characters from Table_ControlKeyCodes into the menu column at 590C using attribute A. B holds how many slots to print (07 for a full refresh, 05 via Print_ControlKeyLabels_Short).
Input
A Attribute value for the labels
Print_ControlKeyLabels F5CA LD B,$07 Load B with 07 label count.
This entry point is used by the routine at Print_ControlKeyLabels_Short.
Walk Table_ControlKeyCodes and print each defined key code.
Print_ControlKeyLabels_WalkTable F5CC LD ($7307),A Store A as the current text attribute (CurrentTextAttribute).
F5CF LD HL,$590C Point HL at the first key's attribute cell (590C).
F5D2 LD IX,$F5FB Point IX at the control key table (Table_ControlKeyCodes).
Print_ControlKeyLabels_NextKey F5D6 LD E,(IX+$00) Fetch this slot's key code into E. Clear D. Call Print_Character to print that character.
F5D9 LD D,$00
F5DB CALL Print_Character
F5DE INC IX Advance IX onto the next slot.
F5E0 LD DE,$0040 Step HL down one menu key-label row (0040).
F5E3 ADD HL,DE
F5E4 DJNZ Print_ControlKeyLabels_NextKey Loop until B labels are printed.
F5E6 CALL ColourCycle_MainMenuLogo Call ColourCycle_MainMenuLogo to colour-cycle the logo (menu acknowledge).
F5E9 RET Return.
