72B6: Task Three Flags
Flags for the task-three (boiled slimies / feeding) state machine. Bit names below are taken from the Bad Tempered Thing dialogue gates and the stove / put-down writers that set or clear them.
Bit Name Meaning
00 MobileHeater Gates Messaging_MobileHeater Mobile Heater / Messaging_TheStovesNoHelp The Stove's No Help (D921); no SET/RES site found
01 Slimies Gates Messaging_Slimies Slimies; set by F110 on put-down of type 09; tested by D901
02 SlimyLoose Gates Messaging_SlimyLoose Slimy Loose !; set by B401 / C6FC; cleared by Update_Stove; if set, D907 skips the line
04 BoilEmUp Gates Messaging_BoilEmUp Boil'Em Up ! / Messaging_Flame Flame ?; set by ScriptRoutine_TaskThreeBerkRightWindow_SetFlagsAndLayout with 05; cleared by Update_Stove; tested by D927
05 BoilEmUpLatch Companion set with BoilEmUp by ScriptRoutine_TaskThreeBerkRightWindow_SetFlagsAndLayout; cleared by Update_Stove / C397; no BIT reader found
06 StoveReady Gates Messaging_TooSoon Too Soon ? / Messaging_HotStuff Hot Stuff (D915) and Messaging_GotAllSlimies Got All Slimies ? (D91B); set by Update_Stove when StoveTick reaches 04
07 StoveUpdated Set by Update_Stove; tested by ScriptRoutine_TaskThreeBerkRightWindow_SetFlagsAndLayout before it sets BoilEmUp / BoilEmUpLatch and swaps the task-creature layout
