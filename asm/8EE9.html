8EE9: State Data: Complex Entities
Table of complex entity state records (000E bytes each). Backed up to Buffer_EntityStateBackup by Backup_Entity_And_Game_State. Field layout: 00 type; 01–03 flags; 04 room 05/06 y and y-extent; 07/08 x and x-extent 09 direction/state; 0A/0B graphic layout pointer 0C/0D extra state. Flags byte 3 at offset 03 (IX+03) for Berk and most movers:
Bit Meaning
00 Script-locked (ignore input; also set while facing / moving up)
01 Facing left (reset = facing right)
02 Mid-interaction / push latch
03 Bit 03 of flags byte 3
04 Bit 04 of flags byte 3 (see Script_PutDown_SetCarryingFlag / ScriptRoutine_PickUpHeld)
05 Bit 05 of flags byte 3
06 Can-fall / gravity latch
07 Rising / special vertical-state latch
Direction / state at offset 09: 01 face left, 02 face right, 04 face down, 08 face up (see script routines ScriptRoutine_FaceRight–ScriptRoutine_FaceDown).
