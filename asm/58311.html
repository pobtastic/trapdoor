E3C7: Plot Message Glyph Half
Used by the routine at Draw_MessageCharacter.
Write one 0008-byte half-glyph from the message font into the screen bitmap under attribute address HL. Applies the roll/shift mode in DD9F and the inverse shift count in DDA0.
Input
HL Attribute-file address for this character
DE Glyph half-index (×0008 into Pointer_CurrentCharacterSet)
Paint the attribute and resolve the screen and font addresses.
