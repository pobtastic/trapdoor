AF01: Initialise Room Display
Used by the routines at Update_Berk_State, Update_Timed_Events, Handle_Berk_Action and Initialise_New_Game.
Print the score and a short attr-file label stream via Print_Menu_Strings, then the held-countdown stream.
Initialise_Room_Display AF01 LD HL,($72DD) Load HL with the score (Score).
AF04 LD IX,$AF17 Point IX at room-display data (AF17).
AF08 CALL Print_ScoreDigits Call Print_ScoreDigits to print Score Digits.
AF0B LD HL,$3C00 Point HL at the ROM character bitmap base (3C00).
AF0E LD ($72F9),HL Write the pointer in HL to the temporary screen pointer (Pointer_CurrentCharacterSet).
AF11 CALL Print_Menu_Strings Call Print_Menu_Strings to print Menu Strings.
AF14 EXX Swap the main register pairs with their alternates.
AF15 LD E,D Copy D into E (build a pointer/offset).
AF16 LD B,A Keep A in B for later.
AF17 JR NZ,$AF39 If the result was non-zero, jump to AF39.
AF19 JR NZ,Initialise_New_Game_SetTickCounter If the result was non-zero, jump to Initialise_New_Game_SetTickCounter.
AF1B JR NC,$AF4D If no borrow/miss was signaled, jump to AF4D.
AF1D LD E,L Copy L into E (build a pointer/offset).

AF36 JR NZ,Initialise_New_Game_SuperBerkRoomByte If the result was non-zero, jump to Initialise_New_Game_SuperBerkRoomByte.
