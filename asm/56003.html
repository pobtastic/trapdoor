DAC3: Messaging: Ghost !
Task-gated prompt. Opens with [ separator, then gate byte 00.
Messaging_Ghost DAC3 DEFB $5B Separator ([); marks the boundary before the next message.
DAC4 DEFB $00 Task-gate byte (00); show this prompt only when the matching task phase allows it.
DAC5 DEFM "GHOST !" "GHOST !".
DACC DEFB $26 Joiner (&); continues into the next prompt in the same menu entry.
