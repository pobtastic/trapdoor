DA23: Advance Dialogue Character
Used by the routines at Update_Bad_Tempered_Thing_Dialogue and Continue_Bad_Tempered_Thing_Dialogue.
Walk HL forward through a dialogue printer string until the next fragment marker ([) or join marker (&).
Advance_DialogueCharacter DA23 LD A,(HL) Fetch the next dialogue byte. Advance the dialogue pointer. Is it a fragment marker ([)? If so, return with HL on that marker.
DA24 INC HL
DA25 CP $5B
DA27 RET Z
DA28 CP $26 Is it a join marker (&)? If so, return with HL on that marker.
DA2A RET Z
DA2B JR Advance_DialogueCharacter Jump to Advance_DialogueCharacter to keep scanning.
