E9EF: Blit Display Buffer Row
Used by the routine at Blit_DisplayBuffer.
Blit one display-buffer tile to the screen. The graphic-set index selects a base from Table_GraphicSetAddresses; the tile index × 08 is added to that base Attribute bit 07 selects the mirrored blit at Blit_DisplayBufferRowLoop (via BitmapMirrorLookup).
Write the attribute and resolve the graphic-set tile address.
