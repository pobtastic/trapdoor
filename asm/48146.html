BC12: Update Eyeball Creature
Used by the routine at GameStart.
Drive the eyeball creature for the current task: refresh its state, movement and stored coordinates.
Update_Eyeball_Creature BC12 LD A,($72A9) Load A with the Learner Berk mode flag (Flag_LearnerBerkMode).
BC15 OR A Is Learner Berk mode flag zero? If not, return.
BC16 RET NZ
BC17 LD A,($9001) Load A with the type of complex entity slot 20 (StateData_Complex_20).
BC1A CP $22 Is complex entity slot 20's type equal to 22? If not, jump to Update_Eyeball_Creature_ArmSpawn.
BC1C JP NZ,Update_Eyeball_Creature_ArmSpawn
BC1F LD HL,($72D9) Load HL with the eyeball script-position pointer (Pointer_EyeballScriptPosition).
BC22 LD ($72CF),HL Store HL in the active script cursor (Pointer_ActiveScriptCursor).
BC25 CALL Update_Eyeball_Creature_State Call Update_Eyeball_Creature_State to update Eyeball Creature State.
BC28 LD HL,($72CF) Load HL with the active script cursor (Pointer_ActiveScriptCursor).
BC2B LD ($72D9),HL Store HL in the eyeball script-position pointer (Pointer_EyeballScriptPosition).
BC2E RET Return.
