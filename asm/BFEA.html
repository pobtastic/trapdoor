BFEA: Script Routine: (25) Task-two entity action
Walk the task-two entity right while its x-extent stays inside the allowed band.
Input
IX Address of complex state data for an entity
ScriptRoutine_TaskTwoWalkRight BFEA LD A,(IX+$08) Load A with the current entity's x-extent.
BFED CP $98 Is the current entity's x-extent less than 98? If not, jump to ScriptRoutine_TaskTwoWalkRight_RunIdleScript.
BFEF JR NC,ScriptRoutine_TaskTwoWalkRight_RunIdleScript
BFF1 INC (IX+$07) Move this entity one character right.
BFF4 INC (IX+$08)
BFF7 JP AdvanceScriptInstruction Jump to AdvanceScriptInstruction to run the next script instruction.
Right-walk finished at X-extent 98: run idle script BirdScript_IdleLoop.
ScriptRoutine_TaskTwoWalkRight_RunIdleScript BFFA LD HL,$BE81 Point HL at bird script data BirdScript_IdleLoop.
BFFD JP ScriptInstruction Jump to ScriptInstruction to execute the script instruction at HL.
