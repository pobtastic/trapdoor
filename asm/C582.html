C582: Script Routine: (2E) Task-three entity action
Run the task-three right-window encounter when Berk is at that window.
Input
IX Address of complex state data for an entity
ScriptRoutine_TaskThreeBerkRightWindow C582 LD A,($7305) Load A with Berk's room-index copy (BerkRoomIndexCopy).
C585 CP (IX+$04) Is Berk in the same room as this entity (IX+04)? If not, jump to ScriptRoutine_TaskThreeBerkRightWindow_CheckCreatureXExtent.
C588 JR NZ,ScriptRoutine_TaskThreeBerkRightWindow_CheckCreatureXExtent
C58A LD BC,($C2E6) Load BC from C2E6.
C58E LD A,($7304) Load A with Berk's X-extent copy (BerkXExtentCopy).
C591 CP B Is Berk's X-extent copy (BerkXExtentCopy) left of B? If so, jump to ScriptRoutine_TaskThreeBerkRightWindow_CheckCreatureXExtent.
C592 JR C,ScriptRoutine_TaskThreeBerkRightWindow_CheckCreatureXExtent
C594 LD A,($7303) Load A with Berk's X-coordinate copy (BerkXCoordinateCopy).
C597 CP C Is Berk's X-coordinate copy (BerkXCoordinateCopy) at or beyond C? If so, jump to ScriptRoutine_TaskThreeBerkRightWindow_CheckCreatureXExtent.
C598 JR NC,ScriptRoutine_TaskThreeBerkRightWindow_CheckCreatureXExtent
