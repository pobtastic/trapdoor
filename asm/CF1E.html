CF1E: Update Crusher
Used by the routine at Update_Entity_Slot.
Called from Update_Entity_Slot on the crusher entity path: set bit 04 of EntityInteractionFlag, advance the shared tick at SharedTick, and once that tick reaches 03 also set bit 06. Bit 07 is set on every call.
Mark Berk crushed and advance the shared tick.

CF1F LD HL,$72B9 Point HL at the entity interaction flag (EntityInteractionFlag).
CF22 SET 4,(HL) Set bit 04 of EntityInteractionFlag.
CF24 LD A,($72C2) Load the shared tick (SharedTick) into A.
