AF3C: Initialise New Game
Used by the routine at GameStart.
Start a new game: reset display buffers, tick counter, menu glyphs and room state for Learner or Super Berk.

AF3F LD HL,$63A0 Point HL at Primary Display Buffer (PrimaryDisplayBuffer).
AF42 LD ($72F5),HL Store HL in Pointer: Current Display Buffer (Pointer_CurrentDisplayBuffer).
AF45 XOR A Clear the display-buffer select flag.
AF46 LD ($72EA),A Set Display Buffer Select Flag (DisplayBufferSelectFlag).
AF49 LD A,$64 Load A with 64 as the initial game tick counter.

AF4E CALL Clear_BothDisplayBuffers Call Clear_BothDisplayBuffers to clear both display buffers.
AF51 LD A,$02 Load A with 02.
AF53 CALL Set_BorderSpeakerState Call Set_BorderSpeakerState to set Border And Speaker State.

AF62 JR Z,Initialise_New_Game_SuperBerkRoomByte
AF64 LD A,$7A Load A with 7A.

Advance the small position count before writing the room/state byte.
Initialise_New_Game_Branch AF6A INC E Advance the low byte of the pointer/offset in DE.

AF6E LD B,$80 Load B with 80 as a loop counter.
AF70 LD D,$00 Clear D (high byte of a pointer/offset).
AF72 LD HL,$5A80 Point HL at the attribute-file base (5A80 (attribute buffer)).
Print a full attribute-file row of glyphs, then initialise the room display.
Initialise_New_Game_PrintAttrRow AF75 CALL Print_Character Call Print_Character to print Character.
AF78 INC HL Advance 5A80 (attribute buffer) by one byte.
AF79 DJNZ Initialise_New_Game_PrintAttrRow Decrease the loop counter in B and jump to Initialise_New_Game_PrintAttrRow if more iterations remain.
AF7B CALL Initialise_Room_Display Call Initialise_Room_Display to initialise the room display.
