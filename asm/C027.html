C027: Script Routine: (27) Task-two entity action
Spawn or refresh a helper entity from the current task-two state.
Input
IX Address of complex state data for an entity

C02A LD B,(IX+$06) Load B with the current entity's y-extent.
C02D LD C,(IX+$07) Load C with the current entity's x-coordinate.
C030 LD IY,$8FD7 Point IY at the spawned-helper entity (StateData_Complex_17).
C034 LD (IY+$00),$06 Write 06 to the referenced entity's entity type.
C038 LD (IY+$04),A Set the referenced entity's room index.
C03B INC C Advance the helper's x-coordinate in C by one.
C03C LD (IY+$07),C Store C in the referenced entity's x-coordinate.
C03F INC C Advance the helper's x-extent base in C by one.
C040 LD (IY+$08),C Store C in the referenced entity's x-extent.
C043 INC B Step the Y value in B on by one.
C044 LD (IY+$05),B Store B in the referenced entity's y-coordinate.
C047 INC B Step the Y value in B on by one.
C048 LD (IY+$06),B Store B in the referenced entity's y-extent.
C04B SET 7,(IY+$01) Set bit 07 of the referenced entity's flags byte 1.

C054 LD ($72B3),A Set the game event flags (GameEventFlags).
C057 LD A,($72C0) Load A with the entity spawn timer (EntitySpawnTimer).

C068 LD ($72B5),A Set the task-two flags (TaskTwoFlags).
