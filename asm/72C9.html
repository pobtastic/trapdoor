72C9: Task Selection Table
Bit 07 marks a task slot as used. Task 05 is chosen separately at AC10.
TaskSelectionTable 72C9 DEFB $00 Task 01 (value not read; bit 07 set once used).
72CA DEFB $02 Task 02.
72CB DEFB $03 Task 03.
72CC DEFB $04 Task 04.
72CD DEFB $40 Wrap marker (bit 06 set).
