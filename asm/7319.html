7319: Bitmap Mirror Image Lookup Table
Entry n holds n with its eight bits in reverse order, so bit 07 swaps with bit 00, bit 06 with bit 01, and so on. Blit_DisplayBufferRowLoop passes each of a tile's eight bitmap bytes through it when the tile's attribute bit 07 is set, which draws the tile mirrored left to right, so one copy of the graphics serves both facing directions.
