E6DB: Populate Display Buffer For Visible Entities
Used by the routine at GameStart.
Walk the simple entity table at StateData_SimpleEntities and process graphic layout data for each visible entity into the current display buffer.
Walk rooms 00–05 and draw every on-camera entity into the current display buffer.
PopulateDisplayBuffer_VisibleEntities E6DB LD C,$00 Clear the room-pass index in C to 00.
Start a room-pass over the simple entity table at StateData_SimpleEntities.
PopulateVisible_StartRoomPass E6DD LD IX,$8B69 Point IX at the simple entity table (StateData_SimpleEntities).
E6E1 LD DE,$000E Load DE with 000E.
Draw each visible entity whose room and camera-window x-band match this pass.
PopulateDisplayBuffer_VisibleEntitiesContinue E6E4 LD A,(IX+$00) Fetch the current entity's type for the type test.
