BEE6: Update Task Two Entity State
Used by the routine at Update_Task_Two_Entities.
Restore the upstairs helper if needed, then either start/stop its script from the game event flags or pick the next wandering script.

BEF2 JR Z,Update_TaskTwo_CheckHelperRestore
BEF4 SET 2,(HL) Otherwise arm the spawn / random-walk latch (set bit 02).
Handle helper restore: rewrite the upstairs helper layout when bit 03 is set.

Update_TaskTwo_SelectEntity BF07 LD IX,$8FE5 Point IX at the upstairs helper entity (StateData_Complex_18).
BF0B LD HL,($72CF) Keep the temporary script pointer in HL (Pointer_ActiveScriptCursor).
BF0E LD A,($72B3) Fetch the game event flags (GameEventFlags).
BF11 BIT 7,A Is a task entity script marked active (bit 07)? If not, take the wander branch at Update_TaskTwo_ScriptBranch.
BF13 JR NZ,Update_TaskTwo_ScriptBranch
BF15 BIT 7,(IX+$00) Is this helper already running (bit 07 of its type)? If not, decide whether to stop it at Update_TaskTwo_StopEntity.
BF19 JR NZ,Update_TaskTwo_StopEntity
BF1B BIT 1,A Is the trap door open (game event bit 01)? If so, (re)start the helper at Update_TaskTwo_StartEntity.
BF1D JR Z,Update_TaskTwo_StartEntity
BF1F JR Update_TaskTwo_ScriptBranch Otherwise wander at Update_TaskTwo_ScriptBranch.
