BD72: Test Thing Upstairs Overlap
Used by the routine at ScriptRoutine_ThingUpstairsChase.
Return 01 in A when the Thing Upstairs entity overlaps Berk on X (BerkXCoordinateCopy / BerkXExtentCopy) and the camera-follow entity (StateData_Berk) on Y while Berk's room copy is 00. Otherwise return 00.
Input
