CBCE: Script Routine: (4D) Task-four entity action
Tick the task-four offer-item timer that gates its dialogue.
Input
IX Address of complex state data for an entity
ScriptRoutine_TaskFourTickOfferItem CBCE LD A,($72C2) Load the shared tick (SharedTick) into A.
CBD1 OR A Is the shared tick (SharedTick) zero? If not, jump to ScriptRoutine_TaskFourTickOfferItem_TickAndOfferItem.
CBD2 JR NZ,ScriptRoutine_TaskFourTickOfferItem_TickAndOfferItem
CBD4 RES 2,(IX+$0D) Reset bit 02 of the current entity's extra state.
CBD8 JP AdvanceScriptInstruction Jump to AdvanceScriptInstruction to run the next script instruction.
Tick SharedTick, flash layout GraphicLayout_Vat_Pouring on the creature, and test whether the offered item is hit.
ScriptRoutine_TaskFourTickOfferItem_TickAndOfferItem CBDB DEC A Step the shared tick back by one.
CBDC LD ($72C2),A Store the shared tick (SharedTick).
CBDF LD IY,$9071 Point IY at the vat entity at StateData_Complex_28.
CBE3 LD BC,$A166 Point BC at graphic layout GraphicLayout_Vat_Pouring.
CBE6 LD ($907B),BC Store BC in the inactive complex-entity slot fields at 907B.
CBEA SET 3,(IX+$0D) Set bit 03 of the current entity's extra state.
CBEE LD A,(IY+$08) Load A with the referenced entity's x-extent.
CBF1 INC A Advance referenced entity's x-extent by one.
CBF2 LD C,(IY+$04) Load C with the referenced entity's room index.
CBF5 LD IY,$900F Point IY at the task-item entity (StateData_Complex_21).
CBF9 CP (IY+$07) Does this entity's x match the referenced entity's x (IY+07)? If so, jump to ScriptRoutine_TaskFourTickOfferItem_HitItemAdvanceAnim.
CBFC JP Z,ScriptRoutine_TaskFourTickOfferItem_HitItemAdvanceAnim
Missed the offered item: set interaction bit 02 of EntityInteractionFlag and clear the offer latch.
ScriptRoutine_TaskFourTickOfferItem_MissItemSetFlags CBFF LD A,($72B9) Load A with the entity interaction flag (EntityInteractionFlag).
CC02 SET 2,A Set bit 02 of EntityInteractionFlag.
CC04 LD ($72B9),A Set the entity interaction flag (EntityInteractionFlag).
CC07 SET 4,(IX+$0D) Set bit 04 of the current entity's extra state.
CC0B RES 2,(IX+$0D) Reset bit 02 of the current entity's extra state.
CC0F JP AdvanceScriptInstruction Jump to AdvanceScriptInstruction to run the next script instruction.
Hit the offered item: play the vat cue, clear the miss flag, and advance its layout animation.
