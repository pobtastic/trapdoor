BECD: Update Task Two Entities
Used by the routine at GameStart.
Once per frame for the "Thing Upstairs" task: refresh helpers, and when the task phase is 02 advance the task-two script at Pointer_TaskTwoScriptPosition.
Update_Task_Two_Entities BECD CALL Update_Task_Helper_Entities Call Update_Task_Helper_Entities to update the task helper entities.
BED0 LD A,($72AF) Fetch the current task phase (CurrentTaskPhase).
BED3 CP $02 Is the phase "run task-two scripts" (02)? If not, return.
BED5 RET NZ
BED6 LD HL,($72D5) Load the task-two script position (Pointer_TaskTwoScriptPosition).
BED9 LD ($72CF),HL Copy it into the active script cursor (Pointer_ActiveScriptCursor).
BEDC CALL Update_TaskTwoEntityState Call Update_TaskTwoEntityState to advance that script / entity state.
BEDF LD HL,($72CF) Reload the (possibly updated) temporary script pointer.
BEE2 LD ($72D5),HL Write it back to the task-two script position (Pointer_TaskTwoScriptPosition).
BEE5 RET Return.
