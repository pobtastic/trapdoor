730B: Table: Addresses of Graphic Sets
Base addresses for graphic sets 00–06. Blit_DisplayBufferRow indexes this table with (set × 02) when blitting a display-buffer tile. Layout opcode F4 writes the set index to CurrentGraphicSetIndex. Index 00 is a never-selected placeholder so the live sets stay on 01–06 matching the F4 operands. F4 never selects set 00.
Set Base Tiles Notes
00 0000 — Placeholder
01 Graphics_Set01 B3 Room scenery / props
02 Graphics_Set02 8F Shared scenery tiles
03 Graphics_Set03 A8 Berk, Drutt, doors, most entities
04 Graphics_Set04 5F Additional scenery
05 Graphics_Set05 65 Trap door / scenery variants
06 Graphics_Set06 3C Extra tiles
