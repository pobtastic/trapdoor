E808: Graphic Layout Routine: (EF) End Loop
Close the current graphic-layout loop and resume after it.
GraphicLayoutRoutine_EndLoop E808 LD A,($7302) Load A with the graphic-layout loop counter (GraphicLayoutLoopCounter).
E80B DEC A Decrease A by one.
E80C LD ($7302),A Set the graphic-layout loop counter (GraphicLayoutLoopCounter).
E80F JP Z,Process_GraphicLayoutData Jump to Process_GraphicLayoutData to process graphic layout data if the comparison matched.
E812 LD IX,($72FF) Load IX with the graphic-layout loop-start pointer (Pointer_GraphicLayoutLoopStart).
E816 JP Process_GraphicLayoutData Jump to Process_GraphicLayoutData to process graphic layout data.
