AAB3: Game Start
Used by the routine at Alias_GameStart.
Relocate initialisation, show the main menu, set up a new game, then enter the main loop.
GameStart AAB3 DI Disable interrupts.
AAB4 LD HL,$6F04 Point HL at Initialisation Source (InitialisationSource).
AAB7 LD DE,$FC6C DE=Initialisation.
AABA LD BC,$0393 Load BC with 0393 (initialisation source copy length).
AABD LDIR Copy the initialisation source to Initialisation.
AABF CALL $FC6C Call Initialisation.
