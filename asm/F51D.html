F51D: Main Menu Select Options
Handle KEYS / JOYSTICK / REDEFINE / CONTINUE on the controls menu. Returns to the caller of Print_ControlsMenu (the Learner/Super pass at MainMenu_ChoosePass) when CONTINUE (C) is chosen.
If keyboard mode is selected, highlight the KEYS option first.
MainMenu_SelectOptions F51D LD A,($F602) If Kempston is already selected (Flag_KempstonJoystickEnabled), skip the KEYS highlight at MainMenu_SelectOptions_KeyLoop.
F520 OR A
F521 JR NZ,MainMenu_SelectOptions_KeyLoop
F523 LD A,$68 Highlight the KEYS option (68) and pulse the menu timing.
F525 CALL Print_ControlKeyLabels
F528 CALL Pulse_MenuTiming
Poll the controls menu for KEYS, JOYSTICK, REDEFINE or CONTINUE.
MainMenu_SelectOptions_KeyLoop F52B CALL Wait_KeyWithMenuMusic Call Wait_KeyWithMenuMusic for one menu-music wait tick.
F52E CALL Read_KeyboardControls Call Read_KeyboardControls to read a key code.
F531 CP $4B Was K (KEYS) pressed? If so, select keyboard at MainMenu_SelectOptions_Keys.
F533 JR Z,MainMenu_SelectOptions_Keys
F535 CP $4A Was J (JOYSTICK) pressed? If so, select Kempston at MainMenu_SelectOptions_Joystick.
F537 JR Z,MainMenu_SelectOptions_Joystick
F539 CP $52 Was R (REDEFINE) pressed? If so, redefine keys at MainMenu_SelectOptions_Redefine.
F53B JR Z,MainMenu_SelectOptions_Redefine
F53D CP $43 Was C (CONTINUE) pressed? If so, return to MainMenu_ChoosePass.
F53F RET Z
F540 JR MainMenu_SelectOptions_KeyLoop Jump to MainMenu_SelectOptions_KeyLoop to keep waiting.
Select keyboard controls and refresh the highlights.
MainMenu_SelectOptions_Keys F542 XOR A Select keyboard controls (clear Flag_KempstonJoystickEnabled) and refresh the menu highlights at MainMenu_SelectOptions_Refresh.
F543 LD ($F602),A
F546 JR MainMenu_SelectOptions_Refresh
Select Kempston and click the menu.
MainMenu_SelectOptions_Joystick F548 LD A,$01 Select Kempston (01 at Flag_KempstonJoystickEnabled) and clear the KEYS column labels.
F54A LD ($F602),A
F54D XOR A
F54E CALL Print_ControlKeyLabels_Short
F551 JR MainMenu_SelectOptions_KeyLoop
Clear the key table to ? prompt for seven new keys, and print each choice.
MainMenu_SelectOptions_Redefine F553 XOR A Select keyboard mode (clear Flag_KempstonJoystickEnabled) before redefine.
F554 LD ($F602),A
F557 LD A,$3F Fill all seven control-key slots at Table_ControlKeyCodes with ? placeholders.
F559 LD HL,$F5FB
F55C LD B,$07
Fill the seven control-key slots at Table_ControlKeyCodes with ? placeholders.
MainMenu_SelectOptions_ClearKeys F55E LD (HL),A Write the placeholder into this slot and step HL onto the next key slot until all seven are cleared.
F55F INC HL
F560 DJNZ MainMenu_SelectOptions_ClearKeys
F562 LD A,$C7 Print the redefine placeholders in attribute C7 and pulse the menu timing.
F564 CALL Print_ControlKeyLabels
F567 CALL Pulse_MenuTiming
F56A LD A,$4F Set the text attribute to 4F for newly typed key labels.
F56C LD ($7307),A

F573 LD HL,$590C Point HL at the first key's attribute cell (590C (attribute buffer)), then remember it in Pointer_ControlKeyDefinitionCursor.
F576 LD ($F5F9),HL
F579 LD B,$07 Load B with 07 keys to redefine.
Prompt for the next of seven redefine-key presses.
MainMenu_SelectOptions_RedefineLoop F57B PUSH BC Stash BC and IX on the stack.
Wait until a fresh key is pressed during redefine.
MainMenu_SelectOptions_WaitUniqueKey F57C PUSH IX
F57E CALL Wait_KeyWithMenuMusic Call Wait_KeyWithMenuMusic for one menu-music wait tick.
F581 POP IX Restore IX from the stack.
F583 CALL Read_KeyboardControls Call Read_KeyboardControls to read a key code.
F586 OR A Was a key pressed? If not, keep waiting at MainMenu_SelectOptions_WaitUniqueKey.
F587 JR Z,MainMenu_SelectOptions_WaitUniqueKey
F589 LD HL,$F5FB Point HL at Table_ControlKeyCodes.
F58C LD B,$07 Load B with 07 to scan for duplicates.
Reject the key if it already appears in Table_ControlKeyCodes; otherwise store and print it.

F59B PUSH AF

F5A0 POP IX

F5AF LD ($F5F9),HL
F5B2 POP BC Restore BC from the stack.

F5BC CALL Print_ControlKeyLabels

F5C2 JP MainMenu_SelectOptions_KeyLoop Jump to MainMenu_SelectOptions_KeyLoop to wait for the next KEYS / JOYSTICK / REDEFINE / CONTINUE choice.
