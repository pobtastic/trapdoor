F9AF: Play Queued Sound
Used by the routines at GameStart, Update_Berk_State, Handle_Berk_Action, Print_EncodedMessage and Clear_AttributeFile.
Play the sound queued at PendingSoundIndex using the parameter block selected from base F907 (sound 01 starts at Table_SoundParameters), then clear the queue. The base F907 is the operand byte of JR NZ in Queue_Sound; it is never read as a parameter because indexes start at 01.
Fetch the pending sound and return if the queue is empty.
Play_QueuedSound F9AF LD A,($7309) Fetch the pending sound index from PendingSoundIndex.
F9B2 AND %01111111 Keep only bits 00–06 (mask 7F).
F9B4 RET Z Return if the queue was empty.
F9B5 PUSH IX Stash IX on the stack.
Point IX at this sound's parameter block and clear the queue.

Load the tone parameters and play.
