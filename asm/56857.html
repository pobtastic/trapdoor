DE19: Print Status Messages
Used by the routines at GameStart and Update_Berk_State.
Print the Learner/Super rating line from Messaging_TooLateIveChangedMyMind, then a task-progress line chosen from the task status flags (TaskStatusFlags).
Choose the rating message from the Learner Berk mode flag (Flag_LearnerBerkMode).
Print_StatusMessages DE19 LD A,($72A9) Load A with the Learner Berk mode flag (Flag_LearnerBerkMode).
DE1C OR A Is Learner mode selected? If so, use the Learner rating at Messaging_AsALearnerIThinkYouAre.
DE1D JR NZ,Print_StatusMessages_Learner
DE1F LD HL,$DDF7 Point HL at the Super Berk rating message (Messaging_AsASuperberkIRateYouAs).
DE22 JR Print_StatusMessages_PrintRating Skip to print it at Print_StatusMessages_PrintRating.
Print_StatusMessages_Learner DE24 LD HL,$DDD5 Point HL at the Learner rating message (Messaging_AsALearnerIThinkYouAre).
Print_StatusMessages_PrintRating DE27 CALL Print_EncodedMessage Call Print_EncodedMessage to print the encoded rating message.
Choose a task-progress message index from TaskStatusFlags / DialogueLineIndex.
DE2A LD HL,$DF0D Point HL at the task briefing/progress table (Messaging_ACompleteFailureYoureFired).
DE2D LD A,($72B4) Load the task status flags (TaskStatusFlags).
DE30 OR A Any task-status bits set? If not, use the dialogue line index at Print_StatusMessages_UseDialogueIndex.
DE31 JR NZ,Print_StatusMessages_FromTaskFlags
Print_StatusMessages_UseDialogueIndex DE33 LD A,($72B0) Load the dialogue line index (DialogueLineIndex).
DE36 INC A Advance it by one for the table walk.
DE37 JR Print_StatusMessages_PrintIndexed Jump to Print_StatusMessages_PrintIndexed to print that indexed string.
Print_StatusMessages_FromTaskFlags DE39 LD A,($72B4) Reload the task status flags (TaskStatusFlags).
DE3C BIT 4,A Did Drutt collect a type-18 object (bit 04)? If so, use index 06.
DE3E JR Z,Print_StatusMessages_Type1CBit5
DE40 LD A,$06 Load message index 06.
DE42 JR Print_StatusMessages_PrintIndexed Jump to Print_StatusMessages_PrintIndexed to print the indexed status string.
Print_StatusMessages_Type1CBit5 DE44 BIT 5,A Did Drutt collect a type-1C object (bit 05)? If not, fall back to Print_StatusMessages_UseDialogueIndex.
DE46 JR Z,Print_StatusMessages_UseDialogueIndex
DE48 LD A,$07 Load message index 07.
Print_StatusMessages_PrintIndexed DE4A CALL Print_MessageString Call Print_MessageString to print the indexed string at HL.
DE4D CALL $FC6C Call RelocatedInitialisation (relocated game tick / redraw helper).
DE50 RET Return.
