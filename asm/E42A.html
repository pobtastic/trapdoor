E42A: Font: Message Characters
Double-height message font used by Paint_MessageBuffer and Draw_MessageCharacter. Each glyph is 0010 bytes: an 0008-byte top half then an 0008-byte bottom half, matching the plot order at E3B8 and E3C0. 002B glyphs run from Font_MessageCharacters through E6D9; E6DA is a pad 00 before PopulateDisplayBuffer_VisibleEntities. E399 maps ASCII codes from 0 upward to glyph slot (ASCII code minus 30); Draw_MessageCharacter_FullStop through Draw_MessageCharacter_Apostrophe override full stop, comma, apostrophe and exclamation mark onto half-indices 14, 16, 18 and 1A (slots 0A through 0D), and space ( ) keeps half-index 20 (slot 10).
