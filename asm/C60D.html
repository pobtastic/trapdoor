C60D: Update Cauldron
Used by the routines at Update_Drutt and Update_Task_Three_Entity_State.
Refresh the cauldron entity after Drutt drops something in, then idle the current task phase.
Update_Cauldron C60D XOR A Clear the current task phase (idle).
C60E LD ($72AF),A Set the current task phase (CurrentTaskPhase).
C611 LD HL,$72B3 Point HL at the game event flags (GameEventFlags).
C614 RES 7,(HL) Clear "task entity script is active" (bit 07 of GameEventFlags).
C616 LD HL,$C2E8 Point HL at task-three storage (C2E8).
C619 LD ($72CF),HL Store HL in the active script cursor (Pointer_ActiveScriptCursor).
C61C LD ($72D1),HL Store HL in the task-three script-position pointer (Pointer_TaskThreeScriptPosition).
C61F LD HL,$C62B Point HL at the 0A-byte init template at Data_CauldronInitTemplate (copied into StateData_Complex_32).
C622 LD DE,$90A9 Point DE at the task-three helper entity slot (StateData_Complex_32).
C625 LD BC,$000A Load BC with 000A (bytes to copy into the helper entity slot).
C628 LDIR Copy the block at HL to DE.
C62A RET Return.
