F454: Draw Menu Background
Used by the routine at MainMenu.
Black out the whole attribute file, then clear a 0E×18 character window starting at 5809 (attribute buffer) for the main-menu / controls layout.
Fill the attribute file, then clear the menu window.
Draw_MenuBackground F454 XOR A Clear A (black ink/paper), then call Set_BorderSpeakerState to fill the attribute file.
F455 CALL Set_BorderSpeakerState
F458 LD HL,$5809 Point HL at the menu window top-left (5809 (attribute buffer)).
F45B LD DE,$0012 Load DE with the per-row skip (0012 bytes).
F45E LD C,$18 Load C with 18 row counter.
Clear one attribute row of the 0E×18 menu window.
Draw_MenuBackground_RowLoop F460 LD B,$0E Load B with 0E column counter.
Black out one attribute cell inside the menu window.
Draw_MenuBackground_ColLoop F462 LD (HL),A Write black at HL. Advance one character. Loop across the row.
F463 INC HL
F464 DJNZ Draw_MenuBackground_ColLoop
F466 ADD HL,DE Step HL by the row skip in DE.
F467 DEC C Decrease the row counter.
F468 JR NZ,Draw_MenuBackground_RowLoop Jump to Draw_MenuBackground_RowLoop if more rows remain.
F46A RET Return.
