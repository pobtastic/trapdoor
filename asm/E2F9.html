E2F9: Skip To Message Marker
Used by the routines at Print_MessageString and Print_EncodedMessage.
Advance HL to the next [ message marker (used while skipping encoded fragments).
Input
HL Message pointer to advance
Skip_ToMessageMarker E2F9 LD A,(HL) Fetch the next byte. Is it a message marker ([)? If so, return with HL on that marker.
E2FA CP $5B
E2FC RET Z
E2FD INC HL Advance the pointer.
E2FE JR Skip_ToMessageMarker Jump to Skip_ToMessageMarker to keep scanning.
