F90F: Table: Sound Parameters
Eight-byte parameter blocks for sounds 01–14. Play_QueuedSound forms IX=F907+(index×08). The base F907 is the operand byte of JR NZ in Queue_Sound; it is never read as a parameter because indexes start at 01, so sound 01 begins here. Layout:
Offset Meaning
00 Outer repeat count (C)
01 Pulse count (B)
02 Speaker-off delay (E)
03 Speaker-on delay (D)
04 Per-pulse delta added to the on-delay
05 Per-pulse delta added to the off-delay
06 Flags / waveform high byte (bit 07 set = square wave only)
07 Waveform low byte when bit 07 of 06 is clear
