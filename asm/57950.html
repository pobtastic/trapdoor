E25E: Select Task Progress Message
Used by the routine at Update_Timed_Events.
Choose which mid-task progress message to show from the current task index (CurrentTaskIndex), then fall into Print_EncodedMessage to print it. Task 05 branches to Print_TaskProgressIntro ("NOT TIDY YET") or Print_WagesMessage ("HERE ARE YOUR WAGES") from bit 07 of TaskStatusFlags; tasks 01–04 index the pointer pairs at Table_TaskProgressMessagePointers (flag byte + message address).
Handle the wages / not-tidy task specially.
Select_TaskProgressMessage E25E LD A,($72AE) Fetch the current task index (CurrentTaskIndex). Is it task 05? If not, use the pointer table at Select_TaskProgressMessage_FromTable.

E265 LD A,($72B4) Fetch the task status flags (TaskStatusFlags). Has the wages bit (bit 07) been set? If not, jump to Print_TaskProgressIntro to print "NOT TIDY YET". Otherwise jump to Print_WagesMessage to print "HERE ARE YOUR WAGES".
