D5F4: Script Routine: (3C) Collectible action
Advance the collectible's room index twice to force a room change.
Input
IX Address of complex state data for an entity
ScriptRoutine_CollectibleIncRoomTwice D5F4 SET 2,(IX+$09) Set bit 02 of the current entity's direction / state.
D5F8 INC (IX+$04) Advance this entity two rooms ahead.
D5FB INC (IX+$04)
D5FE JP AdvanceScriptInstruction Jump to AdvanceScriptInstruction to run the next script instruction.
