Advance the script pointer by two bytes and execute the instruction at HL. A zero high byte means a script opcode (dispatched via TableScriptHandlers); otherwise the word is a graphic layout address stored into the entity at IX.
Input
IX Address of complex state data for an entity
Output
HL Current position in script data
AdvanceScriptInstruction EC2E INC HL Advance HL to the next script byte.
EC2F INC HL Advance HL to the next script byte.
