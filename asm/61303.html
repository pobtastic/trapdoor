EF77: Script Routine: (15) Jump to new script address if entity is carrying something
Used by the routine at AdvanceScriptInstruction.
Input
IX Address of complex state data for an entity
ScriptRoutine_JumpIfCarrying EF77 INC HL Advance HL to the next script byte.
EF78 INC HL Advance HL to the next script byte.
EF79 BIT 4,(IX+$03) Is bit 04 of the current entity's entity flags set? If so, jump to ScriptRoutine_JumpToAddress_FetchAddress.
EF7D JR NZ,ScriptRoutine_JumpToAddress_FetchAddress
EF7F JP AdvanceScriptInstruction Jump to AdvanceScriptInstruction to run the next script instruction.
