CC53: Script Routine: (49) Task-four entity action
Raise the task-four creature one character.
Input
IX Address of complex state data for an entity
ScriptRoutine_TaskFourRaiseY CC53 LD A,(IX+$05) Load A with the current entity's y-coordinate.
CC56 SUB $04 Subtract 04 from A.
CC58 LD (IX+$05),A Set the current entity's y-coordinate.
CC5B LD A,(IX+$06) Load A with the current entity's y-extent.
CC5E SUB $04 Subtract 04 from A.
CC60 LD (IX+$06),A Set the current entity's y-extent.
CC63 BIT 3,(IX+$0D) Is bit 03 of the current entity's extra state set? If not, jump to AdvanceScriptInstruction.
CC67 JP Z,AdvanceScriptInstruction
CC6A RES 3,(IX+$0D) Reset bit 03 of the current entity's extra state.
CC6E LD BC,$A18B Point BC at the vat layout (GraphicLayout_Vat).
CC71 LD ($907B),BC Store BC in the inactive complex-entity slot fields at 907B.
CC75 JP AdvanceScriptInstruction Jump to AdvanceScriptInstruction to run the next script instruction.
