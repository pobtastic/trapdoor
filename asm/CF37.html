CF37: Update Miscellaneous Entities
Used by the routine at GameStart.
Per-frame hook for non-task entities: refresh collectibles and the vat, then snapshot the script cursor so the next vat pass can reload it.
Update_Miscellaneous_Entities CF37 CALL Update_Collectibles Call Update_Collectibles to update Collectibles.
CF3A CALL Update_Vat Call Update_Vat to update Vat.
Copy the script position from Pointer_ActiveScriptCursor to Pointer_DruttScriptPosition so Update_Vat can reload that cursor into Pointer_ActiveScriptCursor on its next entry.
CF3D LD HL,($72CF) Load HL with the active script cursor (Pointer_ActiveScriptCursor).
CF40 LD ($72D3),HL Store HL in the Drutt script-position pointer (Pointer_DruttScriptPosition).
CF43 RET Return.
