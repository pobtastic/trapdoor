72CF: Pointer: Active Script Cursor
Live script-data cursor while a task / entity script runs. Task updaters copy their dedicated script position (Pointer_TaskThreeScriptPosition / Pointer_DruttScriptPosition / Pointer_TaskTwoScriptPosition / Pointer_TaskFourScriptPosition / Pointer_ThingUpstairsScriptPosition / Pointer_BerkScriptPosition) here, call the shared runner, then write the (possibly advanced) cursor back.
