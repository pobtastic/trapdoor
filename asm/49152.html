C000: Script Routine: (26) Task-two entity action
Used by the routine at AdvanceScriptInstruction.
Input
IX Address of complex state data for an entity
ScriptRoutine_TaskTwoWalkHorizontal C000 LD A,($72B5) Load A with the task-two flags (TaskTwoFlags).
C003 BIT 2,A Test bit 02 of task-two flags.
C005 LD A,(IX+$07) Load A with the current entity's x-coordinate.
C008 JR Z,ScriptRoutine_TaskTwoWalkHorizontal_WalkLeftOrBound Jump to ScriptRoutine_TaskTwoWalkHorizontal_WalkLeftOrBound to continue if the comparison matched.
C00A CP $6E Is the current entity's x-coordinate equal to 6E? If so, jump to ScriptRoutine_TaskTwoWalkHorizontal_RunScript_BEB9.
C00C JR Z,ScriptRoutine_TaskTwoWalkHorizontal_RunScript_BEB9
ScriptRoutine_TaskTwoWalkHorizontal_WalkLeftOrBound C00E CP $63 Is the current entity's x-coordinate less than 63? If so, jump to ScriptRoutine_TaskTwoWalkHorizontal_RunScript_BE89.
C010 JR C,ScriptRoutine_TaskTwoWalkHorizontal_RunScript_BE89
C012 DEC (IX+$07) Move this entity one character left.
C015 DEC (IX+$08)
C018 JP AdvanceScriptInstruction Jump to AdvanceScriptInstruction to run the next script instruction.
ScriptRoutine_TaskTwoWalkHorizontal_RunScript_BEB9 C01B LD HL,$BEB9 Point HL at task-two script data BEB9.
C01E JP ScriptInstruction Jump to ScriptInstruction to execute the script instruction at HL.
ScriptRoutine_TaskTwoWalkHorizontal_RunScript_BE89 C021 LD HL,$BE89 Point HL at task-two script data BE89.
C024 JP ScriptInstruction Jump to ScriptInstruction to execute the script instruction at HL.
