CBC3: Script Routine: (4E) Task-four entity action
Arm the task-four script-active flags for the following beats.
ScriptRoutine_TaskFourArmScriptFlags CBC3 LD A,($72B3) Load A with the game event flags (GameEventFlags).
CBC6 OR %10010000 Set bits 07 and 04 of GameEventFlags (task entity script active + upstairs event latch).
CBC8 LD ($72B3),A Set the game event flags (GameEventFlags).
CBCB JP AdvanceScriptInstruction Jump to AdvanceScriptInstruction to run the next script instruction.
