FC84: Menu Music Workspace
Working bytes for the two-channel menu tune. MenuMusic_Workspace and FC85 hold the latest stream bytes; FC86 holds the border and speaker output value written to port FE; FC87/FC89 are stream one's cursor and reload address; FC8B/FC8D are stream two's; FC8F holds the shared delay phase.
MenuMusic_Workspace FC84 DEFB $F4 Latest byte from music stream one.
FC85 DEFB $13 Latest byte from music stream two.
FC86 DEFB $00 Border and speaker bits for port FE.
FC87 DEFW $FE6C Stream one cursor.
FC89 DEFW $FE4C Stream one reload address.
FC8B DEFW $FF4A Stream two cursor.
FC8D DEFW $FF2A Stream two reload address.
FC8F DEFB $E8 Shared delay phase for both channels.
