EDF8: Open Trap Door
Used by the routine at ScriptRoutine_OpenTrapDoor.
Open the trap door: queue a sound, switch the lever graphic layout to open facing right, and update the related scenery entity types.
Open_TrapDoor EDF8 PUSH IX Stash IX, HL and DE on the stack.
EDFA PUSH HL
EDFB PUSH DE
EDFC CALL Check_EntitiesNearTrapDoor Call Check_EntitiesNearTrapDoor to check whether entities require the trap door to open.
EDFF JP NC,TrapDoor_RestoreAndReturn Jump to TrapDoor_RestoreAndReturn to continue if no open is required.
EE02 LD HL,$72B3 Point HL at the game event flags (GameEventFlags).
EE05 BIT 4,(HL) Is "task-two / upstairs event latch" (bit 04 of GameEventFlags) set? If so, jump to TrapDoor_RestoreAndReturn.
EE07 JR NZ,TrapDoor_RestoreAndReturn
EE09 SET 1,(HL) Set "trap door is open / trap door event armed" (bit 01 of GameEventFlags).
EE0B LD A,$05 Load A with sound index 05.
EE0D CALL Queue_Sound Call Queue_Sound to queue sound.
EE10 LD HL,$A7FA Point HL at the lever open, facing right (GraphicLayout_LeverOpenRight).
EE13 LD ($9177),HL Store HL in the lever layout pointer (Pointer_TrapDoorLayout).
EE16 LD HL,$EDC3 Point HL at the open-trap type list (Data_TrapDoorOpenTypes).
