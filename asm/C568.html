C568: Script Routine: (2F) Task-three entity action
Run the task-three left-window encounter when Berk is at that window.
Input
IX Address of complex state data for an entity
ScriptRoutine_TaskThreeBerkLeftWindow C568 LD A,($7305) Load A with Berk's room-index copy (BerkRoomIndexCopy).
C56B CP (IX+$04) Is Berk in the same room as this entity (IX+04)? If not, jump to ScriptRoutine_TaskThreeBerkLeftWindow_CheckCreatureX.
C56E JR NZ,ScriptRoutine_TaskThreeBerkLeftWindow_CheckCreatureX
C570 LD BC,($C2E6) Load BC from C2E6.
C574 LD A,($7303) Load A with Berk's X-coordinate copy (BerkXCoordinateCopy).
C577 CP B Is Berk's X-coordinate copy (BerkXCoordinateCopy) at or beyond B? If so, jump to ScriptRoutine_TaskThreeBerkLeftWindow_CheckCreatureX.
C578 JR NC,ScriptRoutine_TaskThreeBerkLeftWindow_CheckCreatureX
C57A LD A,($7304) Load A with Berk's X-extent copy (BerkXExtentCopy).
C57D CP C Is Berk's X-extent copy (BerkXExtentCopy) left of C? If so, jump to ScriptRoutine_TaskThreeBerkLeftWindow_CheckCreatureX.
C57E JR C,ScriptRoutine_TaskThreeBerkLeftWindow_CheckCreatureX
C580 JR TaskThree_DoorHitThenNextScript Jump to TaskThree_DoorHitThenNextScript to finish this handler.
