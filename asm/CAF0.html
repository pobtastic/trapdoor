CAF0: Script Routine: (50) Task-four entity action
Clear the task-four script flags so the next task-four beat can start cleanly.
ScriptRoutine_TaskFourClearScriptFlags CAF0 LD HL,$72B3 Point HL at the game event flags (GameEventFlags).
CAF3 RES 7,(HL) Clear bit 07 of GameEventFlags (task entity script active).
CAF5 RES 4,(HL) Clear bit 04 of GameEventFlags (upstairs event latch).
CAF7 LD A,$28 Load A with 28.
CAF9 LD ($72F2),A Set the game tick counter (GameTickCounter).
CAFC JR Update_TaskFour_StartEntity Jump to Update_TaskFour_StartEntity to start the entity.
