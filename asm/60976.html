EE30: Check Entities Near Trap Door
Used by the routine at Close_TrapDoor.
Scan complex entity state starting at StateData_Berk. Returns with the carry flag set when the trap door should close (an entity of type 32 is present and nearby entities have been adjusted). Called by Close_TrapDoor.
Output
F Success marker set if the trap door should close
